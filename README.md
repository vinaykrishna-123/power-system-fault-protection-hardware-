# Power System Fault Protection Hardware Prototype

## 📷 Hardware Setup
![Fault Protection Hardware Prototype](hardware_setup.jpg)

## 🛠️ Overview & Components
- **Current Sensing:** Current Transformers (CTs) and sensing modules for continuous current monitoring.
- **Control & Logic:** Automated fault detection logic and comparator/microcontroller circuitry.
- **Actuation:** Relay actuation circuit designed to trigger trip switches under overcurrent conditions.

## 🚀 Key Features
- Detects phase-to-ground and overcurrent fault states in real time.
- Triggers mechanical/electronic relay disconnect within millisecond response times.
